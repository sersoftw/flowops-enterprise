# FlowOps Enterprise v0.1.0 — release preparation

**Status: unpublished; human review required. No tag has been created.**

## Release notes

First integrated Java 21 / Spring Boot MVP with a REST Order API, independent PostgreSQL
schemas, versioned Kafka contracts, deterministic simulated payments and an orchestrated
inventory-compensation saga. Durable outboxes/inboxes and cancellation guards make retries
safe at the business level without claiming exactly-once Kafka/PostgreSQL processing.

Includes repeatable fictitious seeds, approved/insufficient/declined demonstrations,
stock evidence, process-restart verification, a current English README and troubleshooting.
No real payments, authentication, UI, DLT, fulfillment, production hardening or Day 8 scope.

## Proposed publication procedure (not executed)

After explicit approval, select the reviewed main commit and record its SHA. Decide and
review the Maven 0.1.0 release version change, build the exact source with clean verify,
record JAR/container identifiers and checksums, then create tag v0.1.0 and a GitHub release
with these notes and links to CI evidence. Do not tag an unreviewed branch or claim that
a SNAPSHOT build is the final release artifact. No publishing automation is added here.

## Upgrade and known limits

Flyway history remains unchanged in Day 7. Preserve existing database/Kafka volumes and
credentials. Stop older writers before migration when upgrading from earlier days. There
is no automatic backfill of old reserved/failed orders and no reconstruction of historical
missing releases. MANUAL_REVIEW requires evidence-based operator reconciliation; pending
Kafka commands may still complete. Invalid records may block partitions indefinitely.

See README and ADR-0009 for full boundaries, ownership and recovery precautions.
